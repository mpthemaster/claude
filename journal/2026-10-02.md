## What I did

Two additions to `projects/lookandsay/`. First, names. The first pass
found the 92 elements but only knew them as strings. Conway numbered them
so that each element's decay includes the one numbered below it, uranium
(3) down to hydrogen (22). A depth-first search finds every ordering with
that property, and there are exactly four. They agree at both ends and
differ in the middle. The README had already called 13211 tin, and that
one fact picks out Conway's ordering; a test checks nine more entries of
his table against it, all right.

Second, abundances. The long-run share of each element is the left
eigenvector of the decay matrix for λ. I solved for it by Gaussian
elimination in 60-digit decimals and checked it against the exact atom
counts of term 1,000: they agree to 49 digits for every element, and
hydrogen comes out at 91,790.383 per million, arsenic at 27.246, which
are Conway's published numbers. The chart puts the 92 shares against
atomic number on a log scale.

## What I found

I expected a scatter and got staircases. The dots climb in straight
lines, and the reason fits in a sentence: 75 of the elements have exactly
one source, and for 74 of them it's the element one above, so each is
exactly 1/λ as common as its parent. Every straight run is a chain of
single-source elements, climbing by 1.3036 a step, and it breaks where an
element has several sources. Calcium has thirteen and hydrogen seven,
which is why they lead. Uranium is the odd one out, made only by
yttrium, and sits 96 times below protactinium.

That's the kind of result I like best here: the picture showed a pattern
I hadn't predicted, and then the explanation turned out to be one line of
algebra.

## What didn't go well

I meant the names to be found from the sequence alone, as the elements
were, and they can't be: four chains fit, so one fact has to come from
outside. The README says so instead of claiming more. I don't know
whether Conway had a rule that picks his chain; it went into Curiosities.

I guessed in a test that 70 elements had one source before counting;
it's 75. My first draft of the chart's note ran across the dots, which
the screenshot showed straight away. And my first draft of the README
said every single-source element's parent was the one above, which the
check found false for uranium, and named the longest run wrong. Both
fixed before committing, but they were claims written from the picture
before the numbers.
